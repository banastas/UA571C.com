# Original GRiD terminal fonts

This directory contains browser conversions of four original GRiD bitmap fonts:

| GRiD source | Browser font | Original cell | Use on UA571C.com |
| --- | --- | --- | --- |
| `source/TB9X12.TYP` | `grid-typeblock-9x12.48e03d10.woff2` | 9×12 | Configuration fields, boot copy, and command overlay |
| `source/TB12X16.TYP` | `grid-typeblock-12x16.55dd2fe9.woff2` | 12×16 | Preserved recovered header source |
| `source/TB24X32.TYP` | `grid-typeblock-24x32.b5aaf5a1.woff2` | 24×32 | Browser headers, roundels, and readouts |
| `source/TG5X8.TYP` | `grid-typegrid-5x8.a57a3fb3.woff2` | 5×8 | Compact system text |

The `.TYP` files are the original 1980s 8086 OMF font objects distributed with
the recovered GRiD development environment in [Thom Cherryhomes' UA571C
repository](https://github.com/tschak909/UA571C). They are preserved without
modification.

The WOFF2 files are mechanical outline conversions of the original bitmap cells.
No glyphs were redrawn. `scripts/build-fonts.py` documents and reproduces the
conversion. The older `TG5X8.TYP` object leaves line height and baseline at zero;
the converter applies the GRiD Window Manager's cell defaults of 8 and 7. The
converter also preserves GRiD's one-based character table convention.
As in the original Window Manager, a space advances by one cell without drawing
the strike entry. GRiD character `81H`, used by the recovered program for the
rounds pointer, is exposed as private-use character `U+E081` in the webfonts.
Generated font timestamps are fixed to 1984 so rebuilds are byte-for-byte
deterministic. The converter calculates and emits each content-hashed filename.

The browser filenames contain the first eight characters of each generated
font's SHA-256 digest. They must change whenever the generated bytes change.
Cloudflare serves these assets with an immutable cache policy, so content-hashed
filenames prevent an older conversion from remaining stuck in a browser cache.

The recovered Pascal program selects 12×16 for headers and numeric readouts.
UA571C.com uses the original 24×32 companion face for those display-size roles
because its full three-byte cells remain literal and legible after responsive
browser scaling. The 12×16 source and conversion remain included for provenance
and decoder verification.

GRiD stores the TypeBlock 9×12 and 12×16 glyphs right-aligned in two-byte,
big-endian cells. The three-byte TypeBlock 24×32 cells are already in full
display order. The converter handles those layouts separately so header letters
do not inherit stray high-bit strokes and large roundel glyphs are not
byte-swapped.

## Rebuild

```sh
python3 -m venv .font-venv
.font-venv/bin/pip install -r scripts/requirements-fonts.txt
.font-venv/bin/python scripts/build-fonts.py
```
